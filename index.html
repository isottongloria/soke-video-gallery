From Text to Sign: The State of Multilingual Sign Language Production

Visualizing SOKE-based generation across ASL, DGS, Chinese Sign Language, and Phoenix

What is SOKE?

SOKE is a model for sign language production: it takes written text and generates 3D sign-language avatar motion. It is presented in an ICCV 2025 paper.

Most text-to-sign systems treat sign generation as a visual animation task. SOKE treats it more like language modeling: similar to how an LLM predicts text tokens, SOKE predicts sign motion tokens. The core idea is that sign languages have linguistic structure, so motion can be converted into token sequences and generated autoregressively.

Architecture (3 main components)

  1. Decoupled Tokenizer (DETO): three separate VQ-VAE tokenizers are used for upper body, left hand, and right hand, so simultaneous linguistic cues are modeled more effectively.
  2. Autoregressive Multilingual Generator (AMG): after tokenization, sign tokens are integrated with text vocabulary and a pretrained multilingual language model is fine-tuned (mBART-large-cc25 in the paper/repo).
  3. Multi-head decoding: instead of flattening all body-part tokens into one long sequence, SOKE predicts upper-body, left-hand, and right-hand tokens simultaneously at each time step with separate heads while still fusing cross-part information.

Retrieval enhancement: SOKE also uses external sign dictionaries. For words found in the dictionary, it retrieves word-level sign examples, converts them into motion tokens, and provides them as extra context to the language model. This is RAG-like, but it retrieves sign motion examples instead of documents.
